Border Radius

Overrides Tailwind's default radius scale with values tuned for a warm, organic aesthetic. Generous rounding softens the interface and reinforces the brand's approachable quality.

--radius-none0rounded-none
--radius-xs0.125rem · 2pxrounded-xs
--radius-sm0.25rem · 4pxrounded-sm
--radius0.5rem · 8pxrounded
--radius-md0.75rem · 12pxrounded-md
--radius-lg1rem · 16pxrounded-lg
--radius-xl1.5rem · 24pxrounded-xl
--radius-2xl2rem · 32pxrounded-2xl
--radius-3xl2.5rem · 40pxrounded-3xl
--radius-full9999px — pillrounded-full

Usage guidelines: Buttons → rounded-full (pill). Cards → rounded-xl or rounded-2xl. Inputs → rounded-md or rounded-lg. Badges & tags → rounded-full. Modals → rounded-2xl. Images inside cards → match parent radius or use rounded-lg.

06 — Foundation

Animation & Motion

Purposeful motion — slow enough to feel deliberate, fast enough not to frustrate. The spring easing gives interactive elements a satisfying, physical quality.

Duration Tokens
--duration-instant50ms
--duration-fast150ms · hover colors
--duration-normal250ms · most transitions
--duration-slow400ms · reveals, enters
--duration-slower600ms · page transitions
--duration-slowest900ms · background fades
Easing Curves
--ease-outEnters, reveals
--ease-inExits, dismissals
--ease-in-outGeneral transitions
--ease-springButtons, interactions
--ease-smoothCarousels, drawers
--ease-bouncePlayful, notifications

Motion principles: Prefer CSS transitions over JS animations where possible. Use --ease-spring for buttons, toggles, and tap targets — it makes interactions feel physical and responsive. Reserve longer durations for page-level reveals using staggered animation-delay. Always respect prefers-reduced-motion.
